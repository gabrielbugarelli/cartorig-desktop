# CartoRig 2.0.3 — Geographic name overlay

## Purpose
Provide granular place-name overlays without increasing everyday UI clutter. Built on approved 2.0.2 UI Cleanup R3. No changes to the 2.0.0 document schema version.

## Settings
In Looks > Personalize > Map Labels, eight independent category checkboxes select countries, states/provinces, national capitals, regional capitals, populated cities, continents, oceans, and seas. Appearance controls are folded into Typography & density: per-category size (8–60 output-scale pixels), optional color override, label font, density, and text halo. All changes use CommandBus `SetMapLabelOption` and support Undo/Redo. Settings are saved as the optional `map_labels` object in `.cartorig`; older documents lacking this object remain valid and have overlays off by default. Labels do not reset when changing built-in looks.

## Data and limitations
`assets/geodata/map_labels.json` is generated by `tools/build_map_label_catalog.py` from bundled Natural Earth Admin 0, Admin 1 and populated places. 177 country names, 4589 Admin 1 names, 216 national capital entries, 2330 regional capital entries, 4722 populated places, seven continent anchors, nine ocean anchors and 48 seas/gulfs anchor names. Ocean/sea positions and continent positions are **editorial placements**, not hydrographic features. City names inherit English/editorial spellings from the shipped catalog; this is not a localization system. The label catalog is static, not updated automatically when arbitrary GeoJSON is imported.

The name placement engine in `assets/map-labels.js` uses projectable WGS84 anchors, geographic visibility, zoom thresholds, priorities, viewport culling, label budgeting and rectangle-based collision suppression. Country anchors derive from the largest polygon and a representative point. Label positions can be approximate, especially for multipart or elongated features; automatic deconfliction may suppress some names at a given zoom. It is not an atlas-grade manual typesetting engine. Names remain horizontal for legibility when bearing changes. Font sizes track the output resolution rather than the browser window size.

## Export
Standard `renderScene` paints labels between structural map layers and editable objects. Quick PNG, classic ZIP Final Composite and Production flattened/transparent/background PNG include labels. Classic ZIP and Production layered ZIP add an independent alpha-only `Map_Labels.png`. Production SVG includes native `<text>` entries (no rasterization). Selected-object-only outputs and Region Masks intentionally omit global name labels. Tile rendering calculates labels at output resolution for consistent placement across tiles. Renderer and look-preview source locks were updated and thumbnails regenerated.
