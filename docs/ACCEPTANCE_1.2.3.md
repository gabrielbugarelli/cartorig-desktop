# CartoRig 1.2.3 — Acceptance

The **current** acceptance matrix and evidence are maintained in [RELATORIO_HOMOLOGACAO_1.2.3.md](RELATORIO_HOMOLOGACAO_1.2.3.md).

This version includes full, real Natural Earth 1:10m Admin 1 (4,596 administrative features) and full real Natural Earth 1:10m Populated Places (7,342 city points), integrated and independently searchable. The previous incomplete 1.2.3 candidate described in older notes was superseded.

Backend, front-end catalogue, real geographic rendering, project persistence and alpha PNG export tests have been executed. Native Windows setup smoke remains unexecuted in this environment; it is an explicit requirement of the Windows CI acceptance script, so there is no claim of Windows-native homologation.
